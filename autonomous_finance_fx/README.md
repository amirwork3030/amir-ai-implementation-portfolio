# Autonomous Finance / FX Currency Exchange Prototype

Self-directed fintech / Autonomous Finance case study showing how I approach a finance workflow as a Technical AI Business Analyst.

## Scope
The prototype concept maps an end-to-end currency-exchange journey and translates it into business rules, transaction/data requirements, API dependencies, exception paths, control points and prototype-ready logic.

## BA / AI delivery pattern
- Stakeholder / user journey discovery
- AS-IS and TO-BE process definition
- FX rate and transaction-data requirements
- API dependency mapping
- Validation and exception-management rules
- AI-assisted decision-support opportunities
- Human review for material exceptions
- Functional requirements and acceptance criteria
- Python / SQL prototype planning

## Why this matters for Autonomous Finance
The focus is not on using AI as a generic chatbot. It is on identifying where AI and automation can safely support finance operations: interpreting structured/unstructured inputs, checking data, surfacing exceptions, supporting operational decisions and maintaining traceability.

## Status
This is a self-directed portfolio prototype / case study, not a claim of a live regulated production deployment. The public artefacts are intentionally sanitised and use synthetic assumptions/data.
