# Requirements

- BI-01: Support a small, explicit catalogue of business questions.
- BI-02: Convert supported intent into parameterised/controlled SQL, never raw user SQL.
- BI-03: Ask for clarification if a query is ambiguous or unsupported.
- BI-04: Return the query plan and result for transparency.
- BI-05: Record question, recognised intent and execution result in an audit log.
