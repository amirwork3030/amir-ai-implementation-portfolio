# Investment Data Control Centre

A compact Technical AI Business Analyst portfolio demo showing how investment-data quality issues can be surfaced, summarised and routed through a controlled human-review workflow.

## What this demonstrates

- Investment-data flow mapping from source platform through validation, storage, AI analysis and reporting
- Data-quality exception handling for missing classifications, duplicate trades, currency mapping and stale prices
- AI-assisted analyst summaries and recommendations
- Human-in-the-loop controls with approve / escalate / Jira-style actions
- Translation of data issues into implementation-ready operational workflow

## Why it matters

This sample is designed to demonstrate the combination of business analysis, data understanding, AI-assisted workflow design and implementation thinking expected in Technical AI Business Analyst / Data & AI delivery roles.

## Demo

Open `index.html` in a browser to view the interactive visual prototype.

## Next implementation layer

The visual prototype is intentionally lightweight. A production-oriented extension would add Python/Pandas validation, SQL persistence, API integration, automated tests, audit logging and an approved enterprise LLM endpoint.
