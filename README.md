# Amir Iqbal - Technical AI Business Analyst / AI Implementation Work Samples

Hands-on portfolio showing the working pattern expected from a Technical AI Business Analyst / AI Implementation Consultant: stakeholder discovery, process mapping, AS-IS/TO-BE redesign, implementation-ready requirements, Python/SQL prototyping, AI-agent/workflow logic, controls, human-in-the-loop design, testing and auditability.

## Flagship commercial / domain examples

### 1. Social Housing / Property Management AI Operations
A bounded AI-assisted operations workflow for triaging fragmented tenant, contractor, landlord, council/referral and internal messages. The prototype classifies operational intent, identifies urgency/deadlines, routes work to an owner, flags controlled categories for human review and writes an SQLite audit record.

**BA / implementation evidence:** stakeholder workshops, current-state mapping, TO-BE workflow, taxonomy/business rules, user stories/acceptance criteria, human-control design, Python prototype and auditability.

### 2. AI Accounting Practice Automation
Invoice/document triage workflow with validation, confidence scoring, duplicate detection, human-review routing and an SQLite audit log.

**BA / implementation evidence:** AS-IS/TO-BE process analysis, document/data requirements, exception rules, confidence thresholds, human-in-the-loop, UAT thinking and Python workflow prototyping.

## Supporting sample

### 3. Controlled Natural-Language BI Assistant
Natural-language business questions are mapped to a controlled intent catalogue and safe SQL query plan. Unsupported requests trigger clarification rather than unrestricted SQL generation.

**BA / implementation evidence:** data semantics, requirements, supported intents, structured outputs, controls, SQL, transparency and auditability.

## Working model demonstrated

Stakeholder discovery -> process map -> pain points / decision points -> AI suitability -> TO-BE workflow -> requirements + controls -> prototype -> evaluate outputs -> UAT / iterate -> implementation readiness.
